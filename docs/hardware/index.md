# Welcome

This is the documentation site for the NR7Y firmware for Quansheng radios.

## Hardware

This site covers both the original UVK5 firmware, and that for the UVK5v3 and UVK1 Minikong.

To start using the firmware or modifying your radio for CW paddle input, you need to identify which radio model you have, then decide between a cable-based input or the physical paddle rework.
